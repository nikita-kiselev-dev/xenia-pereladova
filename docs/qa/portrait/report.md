# Портретная версия — 24 октября 2026

Основной профиль: **iPhone 13 mini, 375×812 CSS px, DPR 3, touch**. Дополнительные размеры: 375×635, 375×762, 390×844, 768×1024, 812×375; wide smoke — 1440×900 с мышью.

## Результат

- XP монохромный и неподвижный при Overview ↔ List. Декоративный логотип не перехватывает нажатие на первую строку. Верхний blur и custom cursor на телефоне скрыты.
- Phone intro использует верхние XP, подписи и небольшой progress под ними. Desktop фото, большое имя и крупные барабаны в этом режиме скрыты.
- Caption и List последовательно исчезают/появляются; строки раскрываются посимвольно. Дополнительная биография между XP и List удалена из отображения. Footer filters на телефоне скрыты, маршруты категорий и desktop-кнопки сохранены.
- Выход из галереи скрывает XP, caption и список целиком. Сохранённая сцена под первым кадром содержит только обложку. Старая обложка не используется при новом открытии из текстового списка.
- Отмена перехода освобождает сцену для swipe; intro release, caption и cover reveal имеют владельцев и отменяются при новой навигации. Resize во время анимации приводит к пересчёту после завершения.
- Первый кадр phone-проекта занимает 90vw. Увеличение начинается на .33s; возврат сначала уменьшает кадр в центре, затем перемещает его в полосу. Остальные фотографии возвращаются позже. Подписи появляются после уменьшения обложки.
- Fixed метаданные и progress серии защищены белыми gradient-подложками, чтобы проходящие при scroll фотографии не заслоняли текст. Изменение ограничено телефоном.
- Phone progress проекта показывает три цифры процента страницы. При переходе через 600px wide-счётчик сохраняет номер текущей фотографии.
- Info раскрывает текст посимвольно. Портрет и блок следующей серии скрыты на телефоне, как в исходном шаблоне; wide сохраняет эти элементы.

## Публикация

`.github/publication-request.txt` запускает существующий deploy workflow при явном изменении этого файла в `main`. Обычные push без этого файла не публикуют сайт. Это позволяет выполнить разрешённую публикацию через доступный Git SSH: GitHub API credentials и авторизованная browser-сессия в этой среде отсутствуют. Тег не используется: текущая protection policy среды `github-pages` разрешает только branch `main`.

## Границы проверки

Chrome headless использует SwiftShader: эти проверки подтверждают состояние, порядок, геометрию, ввод и завершение переходов, но не FPS реального телефона. Точное попиксельное равенство кадров не утверждается: XP, фотографии и русский контент отличаются; существующая экранная WebGL-проекция сохраняется.

**Не проверено, проверить так:** открыть опубликованный сайт на настоящем iPhone 13 mini/Safari; пройти intro, swipe, Overview/List, Info/Close и серию с прокруткой; раскрыть/спрятать панели Safari, повернуть экран, свернуть/вернуть браузер. Физические safe areas, touch latency и GPU плавность требуют этой проверки. Приёмка пользователем остаётся отдельным этапом.
