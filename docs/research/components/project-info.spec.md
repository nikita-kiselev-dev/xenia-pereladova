# Project / Info

Наблюдения: `reference-project-1440.png`, `reference-info-1440.png`, `reference-info-390.png`.
Файлы: `src/views/project.ts`, `src/views/info.ts`, `src/app.ts`.
Проект: заголовок и Close fixed с полями 20/15px, один figure на 100svh.
Фото сохраняет исходное соотношение, desktop max-height 70svh/max-width80vw; mobile 66svh/92vw.
Подвал показывает текущий номер, полученный IntersectionObserver; Next — обычная ссылка другой серии.
Info desktop: три колонки; заголовок большой слева, текст по центру, портрет 148px справа.
На tablet две колонки и заголовок сверху; mobile вертикальная композиция, портрет125px.
Референсный Info заменён русским заголовком, реальным именем, описанием по фактическим категориям и контактами.
Чужие биография/награды/клиенты не используются. Год съёмки не известен — поле не показывается.
Close/ Escape — возвращение в gallery; неизвестная серия — восстанавливаемая страница ошибки.
Timeline при смене route прерывается, последнее действие остаётся актуальным.
Проверки: desktop/mobile core smoke и responsive smoke пяти размеров.
