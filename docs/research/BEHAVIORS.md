## Неполные наблюдения
Холодный вход в List на 390px сначала дал `[undefined]`; после Overview появилась правильная подпись. Этот дефект источника не переносится.
Настройки точного shader, easing и затухания не подтверждены. Наши GSAP и shader значения — аппроксимация для дальнейшей визуальной калибровки.
Поведение референса на реальных телефонах, все 27 серий, длительные FPS/память и timing видео не проверены.
Чистый hover sweep ограничен: API текущего браузера не предоставляет hover/move. Cursor/underline подтверждены DOM/CSS; точное переключение footer при hover требует дополнительной визуальной сверки.
Нативные screenshot захватывают отдельные кадры перехода; не считать их доказательством motion fidelity.

## Состояние приложения
Hash — запрошенный маршрут. После синхронной замены DOM атрибут `data-page` и `data-phase` обозначают текущий route / переход.
Каждый новый маршрут убивает предыдущую GSAP timeline; DOM никогда не получает pointer-events:none.
Позиция и focus сохраняются по hash галереи; Close и Escape возвращают в предыдущее представление.
Reduced motion: renderer/Lenis отсутствуют, DOM остаётся. GPU error/context loss: DOM возвращается.
