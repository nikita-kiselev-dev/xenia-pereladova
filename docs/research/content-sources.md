# Материалы Xenia

Источник передан пользователем: [старое портфолио](https://pereladova.wfolio.pro/semeynaya-fotosessiya).
Имя Ксения Переладова подтверждено meta description [главной](https://pereladova.wfolio.pro/).
Новосибирск, перечень съёмок и ссылки мессенджеров подтверждены [контактами](https://pereladova.wfolio.pro/contacts).

Импортированы 8 серий: четыре семейные, две из раздела женских портретов, две из раздела праздников.
В каждой — первые восемь кадров (в новогодней серии всего семь); обложки — из прежних listings.
Суммарно: 63 кадра в сериях + 8 обложек + 1 портрет. Для каждого файла есть большая и малая WebP-копия.
Это отбор для первого прохода, не перенос всего архива. Состав и порядок можно менять в manifest.
Оригиналы не изменялись. Публичные web-копии загружены с i.wfolio.ru и перепакованы Pillow без EXIF.
Датировка съёмок, имена клиентов/agency отсутствуют в подтверждённых данных — не добавлены.

`assets-manifest.json` содержит исходные URL, размеры, alt и локальные пути. Генератор — `scripts/import-portfolio.py`.
Описание «Семейные истории, портреты и праздники…» написано для новой версии на основе этих категорий; это не цитата с прежнего сайта.
Название Xenia / инициалы XP взяты из названия проекта и полного имени; требуют визуальной приёмки.
Шрифт IBM Plex Mono распространяется по OFL 1.1, лицензия включена в `public/licenses/`.
Arial/Helvetica — системная замена неизвестного коммерческого display font референса.
